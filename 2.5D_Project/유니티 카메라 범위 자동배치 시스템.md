# 유니티 2D 시네머신 컨파이너 자동화 가이드 (AutoCameraConfiner)

## 1. 프로젝트 배경 및 문제 요약

타일맵 기반 2D 환경에서 `Cinemachine Confiner 2D`를 사용할 때, 바운더리 콜라이더(Boundary Collider)의 실제 크기가 카메라 렌즈 시야 범위(Orthographic Size)와 너무 딱 맞거나 좁으면 카메라 이동이 강제로 고정(Lock)되는 문제가 발생합니다.

이전 작업에서 바운더리 오브젝트의 `Transform.scale`을 크게 설정했을 때 카메라가 정상 추적되었던 원인은 바운더리 영역이 카메라 시야보다 월등히 커졌기 때문입니다. 스케일 계산 방식을 유지하면서도 복잡한 배율 계산 없이 유닛 단위로 손쉽게 여유 공간을 제어하도록 스크립트를 구현하였습니다.

---

## 2. 프롬프트 및 요구사항 발전 과정

1. **카메라 락(Lock) 및 바운더리 문제 인식**
   > *"타일맵 씬에서 Cinemachine Confiner 2D의 카메라 락 문제를 해결하고, 플레이어 추적에 적합하게 바운더리 영역을 자동화하고자 함."*

2. **스케일(Scale) 조절 방식으로 전환**
   > *"콜라이더 크기를 직접 건드리는 대신, 바운더리 오브젝트의 Transform.scale을 조절해서 카메라 범위를 확보하는 방식으로 전환."*

3. **추가 유닛 입력 기반 스케일 자동 계산 (최종 프롬프트)**
   > *"스케일 방식을 유지하되, 인스펙터에서 세로/가로에 추가로 더할 칸 수(유닛)를 입력하면 코드가 알아서 필요한 `localScale` 배율을 자동 계산하여 적용하는 `AutoCameraConfiner` 스크립트 작성."*

---

## 3. 핵심 동작 로직 및 공식

* **기본 맵 크기 수립:** `TileMapData.width`, `height`, `cellSize` 기반 원본 월드 크기 산출.
* **콜라이더 고정:** `BoxCollider2D.size`는 맵 원본 크기로 설정하고, 오프셋(`width/2`, `height/2`)을 중앙으로 고정.
* **스케일 배율 자동 산출 공식:**

$$
\text{Target Scale X} = \frac{\text{Map World Width} + \text{Add Width}}{\text{Map World Width}}
$$

$$
\text{Target Scale Y} = \frac{\text{Map World Height} + \text{Add Height}}{\text{Map World Height}}
$$

* **스케일 적용:** 계산된 `targetScaleX`, `targetScaleY`를 `boundaryTransform.localScale`에 할당.

## 4. 최종 C# 코드 (`AutoCameraConfiner.cs`)

```csharp
using UnityEngine;

public class AutoCameraConfiner : MonoBehaviour
{
    [Header("Target References")]
    public TileMapData currentMapData;

    [Header("Boundary Settings")]
    public Transform boundaryTransform; // Camera_Boundary의 Transform
    
    [Header("Add Extra Units (스케일에 반영할 추가 칸/유닛)")]
    public float addWidth = 0.0f;     // 가로에 추가할 유닛 수 (0)
    public float addHeight = 5.0f;    // 세로에 추가할 유닛 수 (기본값 5유닛)

    void Start()
    {
        if (currentMapData == null)
        {
            FindMapDataFromSaveLoadScript();
        }

        if (boundaryTransform == null)
        {
            boundaryTransform = transform;
        }

        ApplyScaleWithExtraUnits();
    }

    private void FindMapDataFromSaveLoadScript()
    {
        TileMapSaveLoad saveLoadScript = Object.FindAnyObjectByType<TileMapSaveLoad>();
        if (saveLoadScript != null)
        {
            currentMapData = saveLoadScript.stageData;
        }
    }

    public void ApplyScaleWithExtraUnits()
    {
        if (currentMapData == null) return;

        BoxCollider2D boxCollider = boundaryTransform.GetComponent<BoxCollider2D>();
        if (boxCollider != null)
        {
            // 1. 맵의 기본 월드 크기 계산
            float mapWorldWidth = currentMapData.width * currentMapData.cellSize;
            float mapWorldHeight = currentMapData.height * currentMapData.cellSize;

            // 2. 콜라이더 자체는 원본 맵 크기로 깔끔하게 고정
            boxCollider.size = new Vector2(mapWorldWidth, mapWorldHeight);
            boxCollider.offset = new Vector2(mapWorldWidth / 2f, mapWorldHeight / 2f);

            // 3. 사용자가 입력한 추가 유닛(칸 수)을 바탕으로 필요한 스케일 배율을 자동 계산
            float targetScaleX = (mapWorldWidth + addWidth) / mapWorldWidth;
            float targetScaleY = (mapWorldHeight + addHeight) / mapWorldHeight;

            // 4. 계산된 스케일을 오브젝트에 적용
            boundaryTransform.localScale = new Vector3(targetScaleX, targetScaleY, 1f);

            Debug.Log($"[AutoScaleConfiner] 스케일 변환 완료 -> 추가 세로 유닛: {addHeight}, 적용된 Scale Y: {targetScaleY}");
        }
    }
}
```

## 5. 유니티 인스펙터 설정 방법

1. `Camera_Boundary` 게임 오브젝트에 `AutoCameraConfiner.cs` 및 `BoxCollider2D` 스크립트를 첨부합니다.
2. 인스펙터의 **Add Height** 항목에 추가하고 싶은 패딩 유닛 수(예: `5.0`)를 입력합니다.
3. 씬을 실행하면 코드가 자동으로 스케일을 변환하여 적용하므로, 시네머신 컨파이너 락 현상 없이 부드러운 카메라 추적이 이루어집니다.
